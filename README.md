# LOREVA — متجر فساتين | جديدة عرعر

متجر إلكتروني عربي بالكامل (RTL) لبيع الفساتين من **جديدة عرعر**.

- الموقع الحي: https://ahf88711.github.io/samiya/
- المستودع: https://github.com/ahf88711/samiya

## الموقع

- الاسم: LOREVA
- المدينة: جديدة عرعر، منطقة الحدود الشمالية
- الأسعار تبدأ من 600 ريال سعودي

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتحي الرابط الذي يظهر في الطرفية. المسار الأساسي هو `/samiya/`.

```bash
npm run build
npm run preview
```

## الطلب

1. اختاري الكمية والمقاس
2. أضيفي للسلة أو اضغطي **اطلب الآن**
3. أدخلي عنوان التوصيل
4. أكملي الدفع (عند الاستلام أو بطاقة)

الطلبات تُحفظ محلياً في المتصفح (مناسب للعرض والنشر الثابت على GitHub Pages).

## النشر

الموقع منشور على GitHub Pages من فرع `gh-pages`:

https://ahf88711.github.io/samiya/

لتحديث النسخة المنشورة بعد تعديل المصدر:

```bash
GITHUB_ACTIONS=true npm run build
```

ثم انقل محتويات `dist/` إلى فرع `gh-pages`.
